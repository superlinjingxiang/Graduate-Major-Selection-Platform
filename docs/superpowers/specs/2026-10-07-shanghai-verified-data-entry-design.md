# 上海 2027 真实数据入口设计：院校与年度项目身份

**状态：待产品负责人书面评审。** 2026-10-07。
**定位：** 上海真实数据体验闭环的第一个子项目；本规格不宣称全市数据齐全，也不替代后续「决策旅程」与「资讯/数据页」的规格。

## 1. 用户目标和本次边界

产品负责人希望在浏览器里使用真实、可追溯的上海研究生招生数据，走通平台各栏目，从实际体验中决定修改方向；长期目标仍是面向全国所有研究生专业提供基础选择功能。本次先解决完整体验的前置依赖：让已核实的 2027 上海招生单位及其年度项目身份从官方资料进入数据库，并在「院校」页面可浏览、回源。

这里的「院校」同时包含高校与科研院所，按**招生单位主体所在地在上海**确定范围；不以报考点或培养校区替代。当前优先覆盖 2027 年全日制、全国统一考试的硕士项目，学硕与专硕均可纳入。推免、非全日制、单独考试及专项计划不得混入这个分母。全国专业基础目录维持开放，不缩窄为上海。

本次交付不包括招生概率、自动推荐、支付、全市覆盖承诺、2027 考生人数预测、资讯聚合、账户保存或纠错的 Web 全流程；这些分别在后续子项目实现。现有北京试点 API 和数据保持兼容，不能通过改名伪装成上海。

## 2. 两种可选路径与决定

1. **先填充演示数据，再接真实来源：** 页面很快可点，但已经与产品负责人选定的真实数据方向冲突，也可能误导考生；不采用。
2. **先完成全上海核验，再开放任何院校入口：** 覆盖完整，但会延迟验证产品体验，且当前 48 条索引候选尚未核验；不采用。
3. **先做少量真实来源的可追溯纵向切片，再逐批扩展：** 推荐并采用。目标首批 3 家不同类型/学科的招生单位；选择条件是存在适用的官方 2027 章程或目录、可核实单位身份与上海主体所在地，并能由两名不同后台人员完成录入与复核。具体单位不因出现在搜索结果中自动入选。未满足条件时保持候选状态，不能为了凑足 3 家发布。

首批可调查的官方入口包括[上海大学 2027 招生目录入口](https://yjszs.shu.edu.cn/zsjz/sszsjz.htm)、[华东师范大学 2027 招生简章](https://yjszs.ecnu.edu.cn/ef/9b/c43264a782235/page.htm)与[上海师范大学 2027 简章及目录](https://yjsc.shnu.edu.cn/17/99/c17206a858009/page.htm)。这些链接只证明有候选一手来源，**不代表其中任意项目已在 GradMatch 完成字段核验**。

## 3. 现状与依赖

- `InstitutionCoverageEntry`、`CoverageManifest`、单位核码和独立复核的内部流程已具备工程基础；本地 48 条上海索引候选全部仍为待判定，已确认纳入数为 0。候选数不是全市单位总数，也不是可展示院校数。
- `AnnualOffering` 目前只保存粗粒度年度项目身份，缺培养单位、来源原始专业代码、方向/考试组和发布证据；现有 `/api/v1/offerings` 固定读北京试点。
- Web 顶部「院校」仍进占位页；`/search` 与首页仍使用演示项目。直接把候选清单接入页面会违反数据可信边界。
- 本子项目复用 Django、PostgreSQL、Django Ninja、Django Admin 和生成式 OpenAPI 客户端，不引入新服务、独立搜索引擎或另一套前端 DTO。

## 4. 组件与数据流

### 4.1 官方来源台账

为每一份被使用的官方文件登记来源 URL、发布主体、标题、发布日期、适用年度、访问/录入时间、内容摘要或哈希、可定位页码/段落、来源类型及允许的使用边界。文件离线副本若保存，仍须保留原 URL 与采集时间；来源暂时打不开只能标记待复查，不推断停招。

录入先形成候选版本，不直接改写已发布事实。导入程序允许人工录入与可重复的离线文件导入；自动抓取另需来源准入和限速评估，不能绕过登录、验证码、访问限制或站点政策。对同一来源的重复导入应幂等，来源内容变化生成新版本。

### 4.2 身份与证据模型

- 沿用 `Institution` 与上海 `CoverageManifest`。仅当单位官方代码、招生主体所在地、2027 适用来源与纳入结论经独立复核后，单位才具备公开资格。单位改名、同名和隶属歧义保留原始记录，不按名称自动合并。
- 增加培养单位身份；官方目录未区分院系时显式记录「未披露」，不猜测。
- 扩展 `AnnualOffering`：稳定且跨年度不复用的 ID、招生单位、培养单位、原始专业代码、方向/考试组、学位类型、学习方式、招生路径，以及到全国基础目录的映射状态。专业代码或项目名称单独不能充当唯一键。
- 项目身份与每个展示字段分别引用官方来源及定位。发布审查记录保存录入者、复核者、时间、结论、证据版本；复核者必须不同于录入者，且是获授权的后台人员。模型 agent 的代码复核或网页检索不等于此处的人工来源签核。
- `2026` 文件只可形成明确标注的历史对象，不得补齐 `2027` 项目身份或报考条件。冲突、缺失、适用范围不明时保持 `needs_confirmation`/待核验，不生成肯定式结论。

### 4.3 发布门禁与公开接口

公开查询只从经签核的发布视图读取：单位已核码并获纳入、项目身份有适用的 2027 官方目录证据、招生路径/学习方式符合范围，且当前证据版本已由不同人员复核。任何单项不满足时，项目不进入 2027 公开列表；直接请求其 ID 也不得绕过门禁。内部候选列表和审核理由只供授权后台查看。

新增上海范围的只读接口：`GET /api/v1/institutions?region=31&year=2027&q=&kind=&page=1`、`GET /api/v1/institutions/{key}?region=31&year=2027`、`GET /api/v1/institutions/{key}/offerings?region=31&year=2027&page=1`。`region` 和 `year` 必填，本阶段只接受 `31` 与 `2027`，不支持的范围返回 400，不静默退回北京。列表按稳定 key 排序，每页最多 20 条；详情对未发布身份返回 404。响应包含项目年度、范围、身份、证据状态、官方来源链接及来源定位；分页和搜索结果基于数据库，不取前端演示数组。重新生成 OpenAPI 客户端，Web 只消费生成类型。旧北京 `/pilot-scope`、`/offerings` 的语义及测试不改，避免破坏历史工程切片。

公开覆盖说明分别计数：内部候选、经复核单位、经复核项目。普通用户只看到实际可浏览的单位/项目数及「资料持续核验」等产品信息；不能展示内部运维状态、数据库/缓存健康或把候选数量称为全市总量。所有计数使用同一发布门禁查询，避免列表为 0 而标题写 48 家。

### 4.4 Web 院校入口

顶部「院校」进入真实 `/institutions`，提供院校名称搜索、单位类型筛选、已发布单位卡片、年度和覆盖口径提示。院校详情显示官方招生入口、已核验的 2027 项目身份、各字段来源以及通向专业目录/后续项目详情的链接。没有经发布的单位时展示明确空态和官方核验入口，不回退到 `demoPrograms`、48 条候选或 2026 项目。

此页不在缺乏关键字段时显示「可报考」「更容易上岸」等建议。项目的资格、考试、费用和名额将在后续决策旅程子项目按字段证据接入；本次只允许展示已经审核的项目身份及来源。

## 5. 异常、变更和权限

- 官方网页不可访问：保留上一版可审计的已发布数据并标记复查状态；若已知存在新版本但未复核，不自动替换旧字段。无法确认是否仍适用时暂停肯定式当前年度展示。
- 来源冲突：保存两边出处和冲突状态，由授权人员裁定后生成新发布版本；不得静默取较新的网页，也不得用历史年份补缺。
- 单位代码录错：暂停该单位及关联项目发布，走可审计身份纠错流程；不直接在 Admin/SQL 覆写审计历史。
- 公开 API 只返回公开字段；候选来源原文、录入/审核人身份、审核理由和内部路径均不暴露。写接口要求后台认证和权限。
- 录入、复核、发布、撤回均写追加式审计；撤回不删除历史证据，公开列表立即停止返回该版本。

## 6. 验收与测试

1. 在隔离数据库中，测试候选、未核码、未复核、年份错误、来源冲突、学习方式或路径不符的记录均不能经公开接口或直接详情 URL 出现；经不同人员签核的 2027 合规项目才可出现。
2. 同一官方文件重复导入不重复造单位或项目；内容更新产生新证据版本，旧发布版本可追溯；两位操作员不能是同一账号。
3. 同码不同培养单位/考试组、改名单位、研究院所、未披露培养单位和跨年度同名项目各有单独测试，均不按名称或六位专业代码误合并。
4. 公开单位数、项目数与实际列表一致；来源离线、无已发布数据和旧北京试点并存时页面及接口表现稳定且无演示数据降级。
5. 生成的 Core OpenAPI 客户端与后端 schema 一致，TypeScript strict、Django 测试、Web 构建及院校入口端到端测试通过；测试禁止访问真实外部站点。
6. 人工数据验收单独记录实际官方来源、定位、录入者与不同复核者。工程测试通过不等于完成真实资料核验；未得到签核时对外可展示数量应保持 0，不把首批目标 3 家写成已交付事实。

## 7. 后续子项目衔接

本子项目先交付可信的院校/项目身份与公开查询。下一子项目接入字段级报考资格、考试科目、名额口径、费用、比较和三态判断，再接通真实账户保存与纠错复查；「数据」与「资讯」使用有来源的历史统计和官方公告，缺少 2027 官方统计时明确未公布。所有用户页面最终移除演示项目作为正式结果的回退。各子项目分别写实施计划、测试与验收，不以本规格的工程完成宣称全平台闭环。
