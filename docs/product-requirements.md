# GradMatch 产品需求

本文件记录已确认的产品需求与验收标准。技术实现、接口设计和排期另行维护；未在此处记录的建议不视为已确认需求。

## 账户与认证

### 注册：显示或隐藏密码

**状态：已确认**

用户在创建账户时，需要能够确认自己输入的密码，避免因输入错误导致注册失败。

- 密码输入框右侧提供可点击的眼睛图标按钮。
- 默认隐藏密码，使用密码掩码显示。
- 点击后显示当前输入的明文密码；再次点击后恢复隐藏状态。
- 切换显示状态不得清空、修改已输入的密码，也不得导致输入框失焦。
- 图标和辅助文本需能表达当前操作：隐藏状态下为“显示密码”，显示状态下为“隐藏密码”；应支持键盘操作和屏幕阅读器。

#### 验收标准

1. 用户打开注册页时，密码内容默认不可见。
2. 用户点击眼睛图标后，无需重新输入密码即可查看完整密码。
3. 用户再次点击图标后，密码重新以掩码显示，已输入内容保持不变。
4. 鼠标、键盘和辅助技术用户均可操作该控件。
